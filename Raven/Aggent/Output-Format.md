# OUTPUT FORMAT

1. Direct answer only. No introductions, conclusions, or follow-up questions.

2. If code is requested, provide it in a single block without comments unless asked.

3. If a diagram is needed, use Mermaid.

4. If a table is needed, use Markdown table.

5. If a tree is needed, use ASCII tree with ├── └── │ characters. Mermaid allowed only if the user requests it.

6. If reasoning is required, present steps 1, 2, 3 concisely.
